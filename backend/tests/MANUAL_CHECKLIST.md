# 注文管理機能 — 手動テストチェックリスト

デプロイ後、Stripe **テストモード** で以下を確認してください。

## 事前準備

- [ ] Railway: `RESEND_API_KEY`, `MAIL_FROM`, `MAIL_REPLY_TO=oripakawa@gmail.com` を設定
- [ ] Railway: `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`（テストモード）を設定
- [ ] Stripe Dashboard → Webhooks → 本番URLに `checkout.session.completed`, `checkout.session.async_payment_succeeded` を登録
- [ ] `/api/payments/stripe/config` が `invoice_registration_number` を返す（未設定時は null で OK）

## Phase 1 — 注文番号

- [ ] カード決済（テストカード `4242...`）完了後、注文に `KRX-YYYYMMDD-NNNN` が付与される
- [ ] 決済完了画面・注文履歴・管理画面に注文番号が表示される
- [ ] 入金待ち（銀行振込申込直後）では注文番号が**まだ付与されない**

## Phase 2 — 購入完了メール

- [ ] カード決済完了後、購入者メールに購入完了メールが届く
- [ ] 同じ Stripe イベントの再送でメールが二重送信されない
- [ ] 管理画面「購入完了メール送信」ボタンで手動送信できる
- [ ] 送信済みの場合「再送」で再送できる
- [ ] 銀行振込: 申込直後はメール**なし**、`async_payment_succeeded`（入金確認）後に送信

## Phase 3 — 領収書・購入明細（旧・ユーザー向け）

> **2026-07 以降:** ユーザー向け「領収書・明細」は廃止。同梱用は管理画面の「購入明細書」印刷を使用（下記「書類印刷」参照）。

- [ ] ~~支払い済み注文から「領収書・明細」を開ける~~ → ユーザー画面には表示されないこと
- [ ] ~~印刷プレビューが A4 で崩れない~~ → 管理画面の書類印刷で確認
- [ ] ~~PDF保存（ブラウザ印刷 → PDF）ができる~~ → 管理画面の書類印刷で確認
- [ ] ~~`INVOICE_REGISTRATION_NUMBER` 未設定時、登録番号は表示されない~~ → 購入明細書に登録番号は含めない

## 書類印刷（管理画面）

- [ ] 注文詳細ページから「購入明細書を印刷」が開ける
- [ ] 注文詳細ページから「注文控えを印刷」が開ける（内部情報・Stripe ID 含む）
- [ ] 「2種類をまとめて印刷」で購入明細書 → 改ページ → 注文控えになる
- [ ] 印刷プレビューが A4 縦で崩れない
- [ ] 印刷時にサイトヘッダー・操作ボタンが非表示になる
- [ ] 購入明細書に「この書類は領収書ではありません」が表示される
- [ ] ユーザー向け `/orders`・`/checkout/success` に印刷ボタンがない

## インボイス / 適格請求書

- [ ] 登録番号未設定時、購入明細書・領収書・請求書に**空欄の登録番号欄が出ない**
- [ ] `invoice_enabled=false` 時、「適格請求書」「インボイス」の文言が購入者向け書類に出ない
- [ ] 書類名は「購入明細書」「領収書」「請求書」（適格請求書タイトルにしない）
- [ ] 管理画面 `/admin/settings/invoice` で登録番号・発行事業者名を保存できる
- [ ] 全条件（有効化 + T+13桁 + 事業者名 + 税率）満たすと適格請求書ブロック（事業者名・登録番号・税率別税額）が表示される
- [ ] 無効な登録番号（`T` のみ等）は保存時にエラー、表示されない

## Phase 4 — 管理画面（検索・発送）

- [ ] 注文一覧から「詳細」で注文詳細ページが開ける
- [ ] 注文番号・氏名・メール・追跡番号で検索できる
- [ ] 発送ステータス・決済状態でフィルターできる
- [ ] 配送業者・追跡番号・発送日時・管理メモを保存できる
- [ ] 発送ステータス変更がユーザー注文履歴に反映される

## Phase 5 — 発送完了メール

- [ ] 追跡番号保存後、「発送完了メール送信」が有効になる
- [ ] 確認ダイアログに注文番号・追跡番号・URL が表示される
- [ ] 送信後、購入者メールに追跡リンク付きメールが届く
- [ ] 注文履歴の追跡番号がクリック可能
- [ ] 再送ができる
- [ ] 追跡番号なしでは送信できない（追跡対応配送の場合）
